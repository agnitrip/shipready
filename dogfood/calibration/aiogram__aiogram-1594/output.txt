@@ -0,0 +1,11 @@
+Added ``get_value(key: str)`` method to ``FSMContext`` class for direct access to stored values.
+This method allows retrieving a single value from FSM context in one line instead of two:
+
+.. code-block:: python
+
+    # Before
+    data = await state.get_data()
+    name = data["name"]
+
+    # After  
+    name = await state.get_value("name")
